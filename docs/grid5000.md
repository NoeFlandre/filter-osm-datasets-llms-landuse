# Running on Grid'5000

The controller runs on your laptop; frontends only receive light commands
(`oarstat`, `oarsub`, `usagepolicycheck -t`, one status API call, rsync).

```bash
export LUF_WORK=~/luf-work
luf g5k inventory                      # GPU clusters of every site
luf bench plan                         # benchmark as work (parity first)
luf g5k run --datasets benchmark --gpu-models l40s --max-jobs 1 --once
luf status
luf g5k pause [--cancel]  /  luf g5k resume
```

* Jobs request one GPU for one hour (`--checkpoint 300`), only where GPUs are free
  now. Abaca (production) clusters get `-q abaca`; default-queue clusters follow
  the day/night rules (daytime: ≤ 1 h, immediate start, quota-exempt; night: `-t
  night`, ending before the next working-day 09:00).
* `usagepolicycheck -t` runs before and after every submission.
* Clusters that only admit the account in besteffort are remembered and skipped.
* Nodes write content-addressed parts to `~/luf/work`; the controller pulls them.
  No credential ever reaches Grid'5000.
